# Country Search

`createSearch` в `src/search.ts` при каждом изменении ввода отменяет активный запрос через `AbortController` и сбрасывает таймер. Новый запрос ещё не стартовал, но старый уже не может обновить экран во время debounce. Отмена также прекращает чтение тела ответа и освобождает ресурсы. Флаг актуальности сам по себе этого не делает. Сигнал отмены объединён с таймаутом в восемь секунд. Отмена тихая, таймаут и сетевые ошибки показывают сообщение и кнопку повтора. HTTP 404 превращается в пустой массив.

Задержка 300 мс позволяет набрать несколько символов без отдельных запросов и остаётся достаточно короткой для живого поиска. Без неё каждый ввод обращался бы к серверу. С задержкой порядка секунды поиск ощутимо отставал бы от ввода.

`mapCountryResponse` в `src/country.ts` проходит по языкам, валютам и границам один раз. Время и дополнительная память составляют O(L + C + B), где L, C и B — длины соответствующих списков. Остальные поля копируются за O(1).

`src/api.ts` отвечает за HTTP, `src/country.ts` преобразует данные, `src/debounce.ts` управляет таймером, `src/search.ts` управляет состояниями. Каждую часть можно тестировать без DOM и реальной сети. `src/main.ts` создаёт DOM через `createElement` и рендерит состояние в одном месте. Названия состояний совпадают с тем, что видит пользователь. Обложка атласа создана с помощью ImageGen.
